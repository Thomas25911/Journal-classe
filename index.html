👤 Mon compte
Chaque personne a son propre compte protégé par un mot de passe — personne ne peut se connecter sous ton nom sans le connaître. Se connecter en tant qu'Admin demande en plus le code admin de la classe.
Nouveau ici ? Le prénom et le nom servent à t'afficher dans la liste des élèves. Puis clique sur « Créer un compte ». Le premier compte créé sur ce journal devient automatiquement Admin.
